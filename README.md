# Perler Bead Pattern Maker · 拼豆模板生成器

[English](#english) · [中文](#中文)

## English

A small front-end tool that turns images into perler bead patterns and color count lists.

### Features

- Upload PNG, JPG or WebP images
- Set the pattern width and height
- Match colors against built-in bead palettes
- Dithering, transparent-area blanking, and brightness, contrast and saturation adjustments
- Preview the pattern as beads, a grid or numbered cells
- Export the pattern as PNG and the bead count as CSV
- Switch the interface between Chinese and English (中 / EN button in the top-left corner)

### Usage

Open the page and upload an image, or click "Sample image" to try it out.

The project is a single static HTML file and can be deployed directly to GitHub Pages.

## 中文

一个纯前端的小工具，用来把图片转换成拼豆模板和颜色用量清单。

### 功能

- 上传 PNG、JPG、WebP 图片
- 设置拼豆模板宽高
- 使用内置拼豆色卡进行颜色匹配
- 支持抖动、透明留空、亮度、对比度和饱和度调整
- 预览圆豆、格子和编号模板
- 导出 PNG 模板和 CSV 用量清单
- 界面支持中英文切换（左上角的“中 / EN”按钮）

### 使用

打开网页后上传图片，或点击“示例图”快速体验。

项目是单文件静态页面，可以直接部署到 GitHub Pages。
